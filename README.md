# VividChromaGames - Proyecto Integrador

Bienvenido al repositorio central de nuestro proyecto final de Ciencia de Datos y Analítica de Negocios. Este espacio está estructurado siguiendo un flujo de trabajo profesional para garantizar la calidad del código, la reproducibilidad y el cumplimiento estricto de la rúbrica académica.

---

## Estructura del Repositorio
Para mantener el orden visual del proyecto, el código y los entregables se organizarán en las siguientes carpetas:
*   ` src/`: Scripts de código fuente (Simulación, ETL, Modelos).
*   ` notebooks/`: Cuadernos de Jupyter para el Análisis Exploratorio (EDA).
*   ` data/`: Conjuntos de datos (archivos crudos y procesados).
*   ` docs/`: Documentación del proyecto, reportes y manuales.
