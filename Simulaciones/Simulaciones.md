
# Primeras simulaciones de Pimpam Boing

Como parte del inicio de nuestro análisis y con el objetivo de familiarizarnos con el manejo de datos geográficos, se realizó una primera simulación utilizando coordenadas aleatorias obtenidas de Google Maps. En esta etapa no se buscaba representar información real, sino generar un entorno de prueba que nos permitiera comprender cómo podrían organizarse, visualizarse y analizarse los datos dentro del proyecto.

El propósito principal de esta simulación fue explorar la manera en que las coordenadas podían asociarse con las ventas de los diferentes productos del videojuego y observar cómo se distribuirían en un mapa interactivo. Para mantener la prueba sencilla, únicamente se consideraron dos variables: las **ventas** y las **descargas del videojuego**.

Se desarrolló un notebook básico en el que se importaron únicamente las librerías necesarias para crear esta primera simulación y generar las visualizaciones correspondientes.

![importacion,imagen5](ruta de img5-sim)

Posteriormente, las coordenadas fueron colocadas directamente en una celda del notebook para construir un pequeño conjunto de datos de manera manual. Una vez validado su funcionamiento, este dataset fue exportado para posteriormente cargarlo nuevamente y utilizarlo como base en las diferentes simulaciones realizadas.

![importacion,imagen4](ruta de img4-sim)

La primera visualización permitió observar un mapa en el que las **ventas** fueron representadas mediante marcadores de color morado. Además, el tamaño de cada marcador varía dependiendo de la cantidad de ventas registradas en esa zona, lo que facilita identificar de manera rápida las áreas con mayor actividad.

![importacion,imagen3](ruta de img3-sim)

También se generó una representación gráfica donde se comparan las **instalaciones** del videojuego con las **compras** realizadas. Esta visualización permitió tener una primera idea de la relación existente entre ambos indicadores y cómo podrían analizarse posteriormente con datos reales.

![importacion,imagen2](ruta de img2-sim)

Finalmente, se realizó un segundo mapa de prueba enfocado exclusivamente en las ventas. Este ejercicio permitió comprobar diferentes formas de representar la información geográfica y evaluar cuál sería la más clara y útil para la interpretación de los datos.

![importacion,imagen1](ruta de img1-sim)

# ¿Por qué nos fue útil esta simulación?

Aunque esta simulación fue elaborada con datos ficticios, resultó de gran utilidad durante las primeras etapas del proyecto. Nos permitió comprender el flujo completo de trabajo, desde la creación del conjunto de datos hasta su representación visual en mapas y gráficas.

Además, nos ayudó a identificar la mejor forma de organizar la información geográfica, visualizar la distribución de las ventas y las descargas, y analizar cómo podrían relacionarse estos indicadores una vez que contáramos con datos reales.

Gracias a este ejercicio preliminar, fue posible definir una idea más clara de la estructura que tendría el dashboard final, así como de los mapas, gráficas e indicadores que serían más útiles para presentar la información de manera visual, intuitiva y fácil de interpretar.
