# Descripción de Fuentes

## jugadores.csv

Fuente de datos simulada que almacena la información de los usuarios registrados en el videojuego PIM PAM BOING.

Contiene información relacionada con:

- Registro del jugador.
- Edad.
- Tipo de suscripción.

Formato: CSV

---

## productos.csv

Fuente de datos simulada correspondiente al catálogo de mercancía infantil.

Contiene:

- Nombre del producto.
- Categoría.
- Precio.
- Costo.

Formato: CSV

---

## ubicaciones.csv

Fuente de datos geográficos elaborada a partir de coordenadas obtenidas para distintos municipios del estado de Puebla.

Incluye municipios como:

- Xicotepec de Juárez
- Huauchinango
- Tehuacán
- Zacatlán
- Atlixco
- San Andrés Cholula
- Puebla
- Cuautlancingo
- Amozoc
- Chignahuapan

Cada registro contiene un identificador único, municipio, estado y coordenadas geográficas (latitud y longitud), permitiendo realizar análisis espaciales de las ventas.
