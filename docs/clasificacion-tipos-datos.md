# Clasificación de Tipos de Datos

## Según su estructura

- Datos estructurados (CSV)

## Según su naturaleza

- Cualitativos
    - nombre
    - categoría
    - municipio
    - estado
    - tipo_suscripción

- Cuantitativos discretos
    - edad_nino
    - cantidad

- Cuantitativos continuos
    - precio
    - costo
    - latitud
    - longitud

## Según su origen

- Datos simulados
- Datos geográficos

## Según su finalidad

- Datos maestros (productos y ubicaciones)
- Datos transaccionales (ventas)
- Datos descriptivos (jugadores)
